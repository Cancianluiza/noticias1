O que significa HTML?

HyperText Markup Language (Linguagem de Marcação de Hipertexto) - Usado para estruturar a página.

O que é o Flexbox no CSS?

É um modelo de layout unidimensional que facilita o alinhamento e a distribuição de espaço entre elementos.

Qual a função do JavaScript?

Tornar as páginas web dinâmicas e interativas, respondendo a ações do usuário.
